# D’TAILOR Astro site

A responsive, static brand site for D’TAILOR, built with Astro.

## Run locally

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
```

The production output is generated in `dist/`.

## Preview / test link

The live GitHub Pages preview (after deploy) is:

https://jjman9797.github.io/dtalior/

Locally:

```sh
npm run dev
```

Because the GitHub Pages preview lives at `/dtalior/`, local URLs are the same: `http://localhost:4321/dtalior/`.

Pages:

- `/` brand home
- `/shop` WhatsApp catalog by category
- `/about` founder and house story
